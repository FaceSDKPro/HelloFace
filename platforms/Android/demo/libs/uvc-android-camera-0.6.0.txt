public, but no upstream 0.6.0 GitHub Release or Maven Central publication is
claimed. The package manifest binds the clean source and complete delivery.

USB disconnect draining is now included upstream; no local patch is required.
The complete AAR is byte-identical to the previously verified 0.5.0-hotplug.1
candidate, including Java API, JNI keep rules, permissions, licenses, and all
20 native libraries across armeabi-v7a, arm64-v8a, x86, and x86_64.

with DualCameraConfig.defaults(DualCameraConfig.Mode.HIGH). RGB NV21, IR GRAY8,
pairing, and rotation contracts are unchanged. HiFace Demo packages only ARM64
and ARMv7, according to its own ABI filters.
