准备
[ ] Windows 10/11 x64；精简包完整解压后 HelloFace.bat 可直接启动，保留签名旁车及运行 DLL。开发包先 self_test.bat（RESULT: PASS），再 run_demo.bat。
[ ] 精简包无 CLI/源码/合成数据/开发工具；保留 SDK 与第三方许可，未携带演示数据时菜单隐藏导入演示特征入口。
[ ] 准备两位测试人员、同一人的两张照片、另一人的照片、合照及无人脸图片。

主流程
[ ] 录入：独立页采集后先显示预览且库数量不变；确认保存后新增；重复 ID 二次确认覆盖；拒绝覆盖保留预览，可修改 ID 后重试。
[ ] 录入：重新采集、取消、换图或离开页面不写库；相机/图片两条路径均验证。
[ ] 录入：无人脸/合照拒绝采集；单人图片显示待确认预览；超长/空 ID 及拒绝覆盖保留预览，可修正为中文 ID 后保存。
[ ] 录入：待确认时底部主按钮可保存，无相机也可保存图片预览；重新采集/重新打开相机后清除旧预览，取消后不会恢复旧结果。
[ ] 1:N：通过独立录入页保存新 ID 后，返回搜索自动恢复识别并能搜到对应人员；暂停/恢复可用。
[ ] 搜索：结果区显示已应用范围和人数，逐脸显示 ID/分数；空范围、小脸、搜索中、超时、活体失败的提示有区别，候选高分不能冒充已识别。
[ ] 搜索：暂停/停止清空旧结果但保留相机预览，分析 FPS 为 0；暂停时应用参数不自动恢复，有未应用参数时先应用再恢复。
[ ] 搜索：1:N 隐藏人数输入；切到 M:N 后人数输入可用且活体关闭；多脸分别判定，未匹配的人脸不能显示为成功。
[ ] 检测：无摄像头/打开失败时“选择图片并检测”仍可用，顶部保留相机连接重试。
[ ] 检测：自动启动，默认十脸；五点与选定轮廓随人脸移动，眼轮廓1.4倍；不画框/头姿/完整点云；无人脸清除，支持照片。
[ ] 采集参考：临时预览不入库；确认 Face ID 后保存，同名更新；多个 ID 重启保留，取消/重拍不保存，搜索库数量不变。
[ ] 1:1：先选择采集参考再自动验证，默认两步随机动作；有实际分数才显示百分比；重试/关闭可用；HF1 导入须确认，导出/PNG 正常。
[ ] 参考库读取失败时不回退旧 verification.hf1、不重建坏库或选择其他 ID；RGB 搜索与图库仍可使用。
[ ] 活体：自动开始默认三步随机动作，圆形取景与居中步骤提示；完成/拒绝/超时可重试或关闭；离页停止分析。
[ ] M:N：两人同时入镜分别识别，活体自动禁用；暂停/恢复可用。
[ ] 图片搜索：合照按脸显示 ID、分数与缩略图；未录入、无人脸、小脸有明确结果。
[ ] 图片比对：点击方形槽位选图；每槽缓存特征，重复比对不重复提取，只显示原始相似度；坏图保留旧槽，交错换图不串槽，离页清缓存。
[ ] 人脸库：完整 ID 查询/清空，每100条滚动追加，编辑固定ID的分组/标签、删除确认；导入 data\features_10000.json 核对数量，导出后可重新导入。
[ ] 重启：已录入数据与基准保留；完成前取消录入不会写库。

UI 与异常
[ ] 首页按 Android 顺序显示八项网格入口；宽窗口四列两行、紧凑窗口两列四行，960×600 可见全部入口；方向键、Tab、Enter/空格均可操作。
[ ] 窗口仅支持横屏，拖动边框、贴靠、最大化及跨屏缩放保持至少 3:2；小工作区可滚动访问全部入口，不超出屏幕。
[ ] 顶部相机开/关按钮随状态切换；参数区可滚动，应用固定底部；待确认采集保存/重拍/取消不随参数滚动。
[ ] 每个独立页面都有返回按钮；返回或 Esc 先收起本页参数，再回上一级；主功能回首页，录入/人脸库回打开它的功能页。
[ ] 搜索页进入录入并成功保存后自动回搜索；验证页只选独立采集基准，不从搜索库隐式选择；图片搜索查看人脸库后返回保留照片与结果。
[ ] 导入中返回会询问是否停止，停止后保留已保存批次；初始化失败时仍能返回首页并查看日志。
[ ] 离开旧功能后释放相机，新功能按规则自动重开；参数修改/应用、非法输入提示、按钮禁用和取消恢复正常。
[ ] 检测、搜索、验证、录入之间的 ID、人数、阈值、动作和搜索模式草稿分别保留。
[ ] SDK参数设置修改后自动保存，重启保留分辨率、旋转、镜像；预览时可直接切设备、分辨率并重连，设置页和录入待确认时分析 FPS 为 0。
[ ] 参数草稿填入非法阈值/动作后，点击应用提示错误但当前预览/分析继续；切换设备不偷偷应用该草稿；从首页恢复该草稿时不自动开相机，不误启动其他功能的流程。
[ ] 快速多次换图、取消、返回能及时生效，不因旧任务满队列而卡在页面；A/B 换图互不取消，旧失败不覆盖新任务提示。
[ ] 换图片后清除旧比对结果；导入 HF1 不借用旧照片预览；缺失参考不自动使用上一位人员。
[ ] 100/125/150/200% 缩放及横屏窗口下文字、按钮、滚动、Tab 焦点和预览布局可用。
[ ] 图片选择支持中文/空格路径；左图右列表、结果纵向滚动、缩略图点击、方向键、复制详情及 Ctrl+O/F5/Esc 正常。
[ ] 换图、离页或取消后，旧结果不覆盖新任务；旋转/镜像后框与画面对应。
[ ] 相机连续开关 5 次、运行 10 分钟；占用/拔插后有提示且能恢复，无崩溃或卡死。
