HiFace Windows Demo 验收清单
记录：日期____  Windows版本____  CPU____  摄像头____  显示缩放____

准备
[ ] Windows 10/11 x64；完整解压，先 self_test.bat（RESULT: PASS），再 run_demo.bat。
[ ] 准备两位测试人员、同一人的两张照片、另一人的照片、合照及无人脸图片。

主流程
[ ] 录入：独立页采集后先显示预览且库数量不变；确认保存后新增；重复 ID 可修改后重试。
[ ] 录入：重新采集、取消、换图或离开页面不写库；相机/图片两条路径均验证。
[ ] 录入：无人脸/合照拒绝采集；单人图片显示待确认预览；超长/空 ID 和重复 ID 失败保留预览，可修正为中文 ID 后保存。
[ ] 录入：待确认时底部主按钮可保存，无相机也可保存图片预览；重新采集/重新打开相机后清除旧预览，取消后不会恢复旧结果。
[ ] 1:N：通过独立录入页保存新 ID 后，在搜索页打开相机能搜到对应人员；暂停/恢复可用。
[ ] 搜索：结果区显示已应用范围和人数，逐脸显示 ID/分数；空范围、小脸、搜索中、超时、活体失败的提示有区别，候选高分不能冒充已识别。
[ ] 搜索：暂停/停止清空旧结果但保留相机预览，分析 FPS 为 0；暂停时应用参数不自动恢复，有未应用参数时先应用再恢复。
[ ] 搜索：1:N 人数输入禁用；切到 M:N 后人数输入可用且活体关闭；多脸分别判定，未匹配的人脸不能显示为成功。
[ ] 检测：框和点位随人脸移动；无人脸时清除；选择图片也能检测。
[ ] 1:1：采集基准，本人通过、他人不匹配；导出 HF1/对齐 PNG，再导入 HF1 后可验证。
[ ] 活体：动作与静默活体均有清楚结果；取消后可重新开始。
[ ] M:N：两人同时入镜分别识别，活体自动禁用；暂停/恢复可用。
[ ] 图片搜索：合照按脸显示 ID、分数与缩略图；未录入、无人脸、小脸有明确结果。
[ ] 图片比对：同人、异人结果合理，无人脸时提示明确。
[ ] 人脸库：编辑分组/标签、筛选、删除；导入 data\features_10000.json 核对数量，导出后可重新导入。
[ ] 重启：已录入数据与基准保留；完成前取消录入不会写库。

UI 与异常
[ ] 首页按 Android 顺序显示八个纵向功能入口；鼠标滚动、上一屏/下一屏、PageUp/PageDown 和 Tab 可访问全部入口。
[ ] 每个独立页面都有返回按钮；返回或 Esc 先收起本页参数，再回上一级；主功能回首页，录入/人脸库回打开它的功能页。
[ ] 搜索页进入录入并成功保存后自动回搜索；验证页选择库内基准后自动回验证；图片搜索查看人脸库后返回保留照片与结果。
[ ] 导入中返回会询问是否停止，停止后保留已保存批次；初始化失败时仍能返回首页并查看日志。
[ ] 切换任何独立页面后相机关闭；参数修改/应用、非法输入提示、按钮禁用和取消恢复正常。
[ ] 检测、搜索、验证、录入之间的 ID、人数、阈值、动作和搜索模式草稿分别保留。
[ ] SDK参数设置应用后重启保留分辨率、旋转、镜像；设置页和录入待确认时分析 FPS 为 0。
[ ] 换图片后清除旧比对结果；从库内 ID/HF1 换基准后不导出上一张抓拍。
[ ] 100/125/150/200% 缩放及窄窗口下文字、按钮、滚动、Tab 焦点和预览布局可用。
[ ] 图片选择支持中文/空格路径；缩略图点击、方向键、复制详情及 Ctrl+O/F5/Esc 正常。
[ ] 换图、离页或取消后，旧结果不覆盖新任务；旋转/镜像后框与画面对应。
[ ] 相机连续开关 5 次、运行 10 分钟；占用/拔插后有提示且能恢复，无崩溃或卡死。
