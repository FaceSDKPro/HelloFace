# HiFace Windows Demo

人脸搜索连续 10 秒成功检测均无人脸后，预览消费与转换目标为 10 FPS，SDK 分析上限为 5 FPS；
发现人脸后恢复活跃节奏。预览刷新独立于 SDK 跳帧；暂停、离开页面和相机错误会重置待机状态。
这是应用侧限流，摄像头硬件采集帧率仍由设备决定。

支持 Windows 10/11 x64 横屏桌面。精简运行包完整解压后双击 `HelloFace.bat`；
可选开发包进入 `demo/`，先运行 `self_test.bat`，看到 `RESULT: PASS` 后运行 `run_demo.bat`。
保留完整目录，无需开发工具或下载模型。

## 源码主流程

- `main.cpp`：窗口、每页参数草稿、导航和快照展示；`action()` 处理导航和用户确认后发送命令，`update()` 根据工作线程快照更新界面。
- `app.cpp`：一个工作线程串行持有 SDK、人脸库与相机。先处理命令，再预览/分析；`worker_commands.h` 在命令成功入队后推进页面代次；取消/离页清理过期排队任务，A/B 槽各只保留最新待处理换图，旧结果和旧错误不会覆盖替代请求。
- `demo_service.cpp`：把 SDK 结构化结果转换为展示文案；采集只返回临时结果。`EnrollmentDraft` / `ReferenceDraft` 在确认后执行保存，取消不写库。
- `win_util.cpp`：WIC 图片读写、共用的 HF1 有界读取和原子导出、COM 与日志。
- `source/integration/`（完整开发包中的接入示例）：调用公共 C ABI 的 Client/Database/Frame 示例。`Client::process()` 分派检测/流程或搜索；结果与 mesh 在 SDK 缓冲释放前复制。

主流程及重要方法的中英文注释重点说明所有权、线程、取消和写库边界。SDK 不负责 Demo 页面或人员录入策略。

## 使用

首页与 Android 对齐，按原顺序排列八项网格入口：检测、人脸采集、动态 1:1、活体、人脸搜索、双图片比对、图片搜索、SDK参数设置。宽窗口四列两行，紧凑窗口两列四行；标准工作区最小客户区 960×600，窗口始终保持至少 3:2 横屏。受限工作区保留滚动；方向键移动卡片焦点、Tab 切换控件，Enter/空格打开。鼠标滚轮、上一屏/下一屏或 Page Up/Down 浏览，Home/End 跳到首尾。
相机选择与功能入口合并在顶部工具栏，预览占据主要区域；参数在可收起侧栏，保存、重拍、取消置于固定底栏。
各独立页面顶部都有“返回”；主功能返回首页，子页面返回打开它的功能页。录入和人脸库从人脸搜索页进入；图片搜索也可打开人脸库。动态验证使用独立采集参考列表，不用搜索人脸库代替。界面不再提供全局页面侧栏。
离开相机功能页关闭相机、取消流程并丢弃未确认采集。检测、人脸采集、活体、RGB 搜索和搜索内录入进入后自动连接摄像头并启动；从人脸库或录入返回搜索自动恢复并使用最新人脸库。动态验证先显式选择已采集的 Face ID，再自动打开相机。无设备或打开失败保留页面提示，可刷新后重试。
无摄像头或打开失败时，检测页的“选择图片并检测”仍可使用；顶部相机按钮单独负责连接和重试。
Windows 当前只提供 RGB 单摄搜索，不安排红外活体或双目搜索界面。
人脸搜索与普通 Linux 桌面使用相同的处理节奏：活跃时最高 25 FPS 预览、8 FPS 分析；连续 10 秒成功检测均无人脸后，降为最高 10 FPS 预览、5 FPS 分析。检测到任意人脸（包括未匹配或活体拒绝）即恢复活跃节奏，不等待身份匹配成功。工作线程按截止时间等待，只保留最新相机样本，减少画面转换、绘制和推理开销。
无人脸时长按样本到达时间统计；过期结果、SDK 跳帧和断流不作为无人脸证据。超过 3 秒没有新检测，以及暂停、离页、重连或错误均清除待机判断。Windows 不切换相机硬件帧率或系统亮度；Media Foundation 的采集速率仍由设备与驱动决定，实际功耗需真机测量。
人脸搜索的画面下方显示当前已应用的模式、活体开关、阈值、分组/标签和搜索范围人数，并逐脸显示识别状态、ID 与相似度；结果文字可选择复制。
1:N 固定处理一个主目标，M:N 可设置最多 1–5 张脸并关闭活体。未完成搜索或活体未通过时，相似度仅为候选分数，不表示身份已确认。
暂停或停止搜索后清空当前结果、停止人脸分析并保留相机预览；恢复后重新识别。暂停期间应用参数仍保持暂停；有未应用修改时先应用再恢复。范围为空时检查分组/标签，或从录入、人脸库入口添加人员。
检测、验证、活体和搜索的参数从本页顶部“参数设置”打开；收起参数或按返回先回到本功能，草稿仍保留。校验失败不会中断当前分析；从首页恢复无效草稿时只打开页面，修正前不自动启动相机或回退到其他功能的流程。参数修改后点击“应用修改”，进行中的流程可取消。摄像头分辨率、旋转和镜像集中放在 SDK参数设置页。
各功能页分别保留人数、阈值、动作、搜索模式/间隔/超时和人员字段草稿，不会从另一页带入参数。
搜索设置中，1:N 显示静默活体开关，M:N 显示最多 1–5 脸。支持恢复默认、取消修改和应用后收起；显式暂停搜索时应用参数继续保持暂停。ID、分组、标签及查询输入统一去掉两端空白，路径不作此处理。
搜索预览断流超过 0.5 秒、分析结果超过 1.2 秒或页面代次变化时隐藏旧身份框和匹配分数，等待新结果，不沿用旧身份。
SDK参数设置的分辨率、旋转与镜像修改后自动原子保存到 `camera-settings.txt`，下次启动读取；预览中可直接切换设备和分辨率，自动重新连接。切换设备沿用已应用的 SDK 参数，未确认的阈值/动作/范围草稿保持原样；设置页只预览，不执行人脸分析。Windows 旋转视频和分析坐标，保持原生窗口与输入控件方向；不移植 Linux 嵌入式的整页旋转、板级灯控或视频格式输入。

- 人脸库提供独立的完整 Face ID 查询框；清空后恢复全库。每批读取 100 条，滚动到距末尾十条时自动预取并追加，不跳回顶部。空库、未找到和读取失败分别提示。
- 双击人员或右键选择编辑资料，Face ID 固定，只修改分组和标签；保存失败可修改重试。右键删除先确认具体 ID。右上角菜单集中刷新、本地图片、HF1 JSON 交换及释放缓存。导出全库不受 Face ID 查询影响。
- 可选开发包的人脸库菜单可直接导入 `data/features_10000.json` 的 1 万条 AI 合成人脸特征；相同 ID 会覆盖；精简运行包不带这些数据并隐藏该入口。
- `data/images_1000.json` 是 1000 张 AI 合成人脸图片的公开 URL 清单，供下载参考；图片使用本地多选导入，不要将此文件作为特征 JSON 导入。
- 图片搜索：左侧显示大图，右侧显示可复制详情及纵向结果列表；选照片查看每张人脸的 ID、分数和对齐图；默认全库 Top-1 / 0.80，不执行活体。
  `Ctrl+O` 选图、`F5` 重搜，方向键选择人脸、滚轮浏览；“取消”停止搜索，“返回”或 `Esc` 取消后返回上一页。从人脸库返回图片搜索时保留原照片、选择和结果。

数据位于 `%LOCALAPPDATA%\HiFaceDemo`：`hiface-search.db` 为搜索人脸库，`captured-faces.db` 为独立采集参考库，`logs/` 为日志与自检报告。旧 `verification.hf1` 不自动读取、迁移或删除；需要的特征可由用户显式导入并确认保存。
可将环境变量 `HIFACE_DATA_DIR` 设为绝对目录以隔离测试数据；未设置时沿用系统用户目录。
相机打不开时检查 Windows 桌面相机权限、设备占用和 Media Foundation；缺 DLL 时重新完整解压。
SDK正在Beta 迭代公测中，请及时升级SDK版本。主流程与界面验收见包内 `Windows真机测试清单.txt`（源码位于 `../package/`）。

## 独立录入流程

从人脸搜索页进入“人脸录入”后自动开始引导采集；可重新采集，或选择图片再点击“从图片采集”。
页面显示“采集 → 核对确认”两步；待确认时底部主按钮切换为保存，仍可通过底部“重新采集”重拍。未开始采集和待确认期间只预览相机，不做人脸分析。
图片必须为清晰的单人正脸；无人脸或检测到多人会拒绝录入并提示重新选择或裁剪，不自动挑选最大人脸。
采集成功只保留临时预览，此时人脸库数量不会增加；填写人员 ID、分组和标签，核对预览后点击“确认保存”。
空 ID 会拒绝保存。已有 ID 会再次询问是否覆盖；选择“否”保留当前预览和资料，可修改 ID 后重试。只有明确确认覆盖才更新已有人员。保存期间不离页；失败保留预览供重试。重新采集、取消、选择另一张图片或离开本页会丢弃待保存结果。
确认保存成功后自动回到人脸搜索并恢复识别；保存失败保留预览供修正。搜索页只负责 1:N/M:N 识别和暂停/恢复，录入与人脸库使用独立子页面。导入中返回或关闭窗口会先确认停止，保留已提交批次。

## 采集、动态验证与活体

首页“人脸采集”自动启动圆形取景与引导，成功后仅形成临时预览。填写 Face ID 并确认保存后写入独立采集参考库，成功返回首页；相同 ID 更新对应参考，不新增另一条。重拍、取消或离页均不保存。可选择单人照片或显式导入 HF1；HF1 文件不包含预览图，导入后仍须填写 ID 并确认。

动态验证先从上方列表选择采集 Face ID；没有参考时显示“先采集基准”。每轮默认两个不同随机动作、开启静默活体并允许多人画面处理主目标。独立活体默认三个不同随机动作。圆框上方显示步骤提示；完成、拒绝或超时弹窗提供重试与关闭，重试重新随机。结果只在 SDK 实际返回相似度时显示百分比，不把早期失败伪装成分数。

实时检测默认最多十脸，显示五点及嘴唇、双眼、鼻部和脸部外轮廓；双眼轮廓放大 1.4 倍，索引与 Android/Linux 一致。默认不显示检测框、头姿标签、眉毛或完整点云。当前 Android 仍绘制检测框和置信度；Windows 此处采用 Linux 的简洁展示。

## 双图片比对

点击任一方形照片位或“选择图片 A/B”选图，选图后提取并缓存各自特征。两侧就绪后启用底部比对按钮；重复比对只比较缓存特征，不重新运行模型。显示原始相似度百分比，不额外设置通过/不匹配阈值，也不把分数解释为身份概率。未得到分数时不预留分数栏。

新照片读取或提取失败只在对应槽位提示，保留该槽原照片与特征。两个槽位分别判断异步请求是否过期；更换一侧不会取消另一侧的有效提取。离页释放缓存并使旧请求失效。

## Android 对照与验证边界

| Android 细节 | Windows 当前行为 |
|---|---|
| 首页功能卡片、独立 Activity | 仅八个纵向入口，顺序相同；录入、人脸库在所属功能内进入 |
| 返回与功能参数 | 每页顶部返回；子页回入口功能；参数按功能展开/收起，无全局页面侧栏 |
| 相机功能自动启动 | 检测、采集、活体、搜索及搜索内录入自动连接；动态验证先选择参考；无相机时保留本地图片入口 |
| 录入后预览并确认保存 | 相机/图片均先形成临时草稿，确认后才写库；取消或离页不写库 |
| Activity 页面状态隔离 | 参数草稿按页保存；离页释放相机和临时录入；图片搜索仅在人脸库子页打开期间保留原结果 |
| SDK参数设置跨重启保留 | 修改后自动原子保存分辨率、旋转和镜像；损坏文件回退到默认值 |
| 相机资源与分析生命周期 | 每次离页停止采集与流程；SDK参数设置及待确认录入阶段不做推理 |
| 基准与人脸库 | 多 Face ID 的独立采集参考库，与搜索人脸库分开；确认保存后可在动态验证中选择 |
| 双图片比对 | 单槽提取与缓存、换图失效、错误保留及原始百分比分数，不新增 Demo 阈值 |
| 搜索人脸库与重复 ID | 完整 Face ID 查询、每批 100 条滚动追加、独立资料编辑/删除确认；录入已有 ID 需第二次明确确认覆盖 |
| 网络图片导入 | 使用本地多选图片与公开 URL 清单，尚无 Android 的网络下载进度界面 |
| 页面亮度 | 不模拟 Android 的窗口 90% 亮度策略；Windows 亮度由系统/显示器管理 |

布局回归覆盖 100/125/150/200% 几何尺寸；实际 Windows 高 DPI、输入法、相机权限/占用/拔插、
长时间运行、真人识别和照片/视频活体攻击效果仍须真机验收。Wine 与交叉编译检查不能替代这些项目。
修改 Demo 时保持 SDK、公开 ABI 与稳定模型发布策略，构建和设备验收分别记录。

## 修改与编译

使用完整 SDK/Demo 包时，在平台根目录运行 `build_demo.ps1`。
单独的 Demo 包需另备 SDK、Visual Studio 2022 C++ 桌面工具和 CMake 3.22.1+，在本 Demo 目录执行：

```powershell
cmake -S source -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH=C:/HiFace/sdk
cmake --build build --config Release
./build/bin/Release/hiface_demo.exe
```

`source/` 包含界面、相机和业务流程；`source/integration/` 是调用 SDK 公共 C API 的 C++ 示例。

## 构建后的程序包

重新编译 EXE 或替换 DLL 后，在导出的 Demo 根目录使用包内 `tools/sign_product.py`
更新匹配的 `.hfpackage`。工具路径相对于该 Demo 根目录；版本读取同包的
`sdk-metadata.json`，发布密钥保留在构建端。示例：

```powershell
$SdkVersion = (Get-Content -LiteralPath sdk-metadata.json -Raw | ConvertFrom-Json).version
python tools/sign_product.py --platform windows --root . --entry bin/hiface_demo.exe --sdk bin/hiface.dll --private-key C:/secure/publisher.pem --product-id com.hiface.demo --version $SdkVersion --replace
```

CLI 使用自己的 `bin/hiface_cli.exe.hfpackage`，并采用相同产品和发布密钥。SDK 的固定版本、头文件、导入库与 DLL 须匹配。HF1 与人脸数据库未加密，导出反馈前移除个人数据和本机路径。
