HiFaceSearchBatchHandle

Types
typedef struct HiFaceSearchBatchOpaque* HiFaceSearchBatchHandle;
Camera search v1. Calls borrow session/database; destroy them only after in-flight calls finish. One batch at a time: prepare -> read detection geometry -> resolve (outside engine lock) -> complete -> read final state -> destroy. Stop invalidates outstanding batches. Destroying an unfinished batch releases admission; it is safe after Session destruction. Continuous search admits at most one frame per 100 ms; skipped frames return FRAME_SKIPPED. All timestamps use a monotonic millisecond clock; resolve includes elapsed I/O. Bounds are rotated, unmirrored image pixels. No cross-frame identity tracking.

hiface_feature_compare_v1

Functions and methods
HIFACE_API HiFaceStatus HIFACE_CALL hiface_feature_compare_v1(
        const float* probe,
        const float* reference,
        size_t feature_count,
        float* out_score);
Compare two face features. feature_count must equal HIFACE_FACE_FEATURE_DIMENSION. Both vectors must contain finite values and have nonzero length; otherwise the function returns INVALID_ARGUMENT and sets *out_score to 0. The score is in [0, 1], mapped from a cosine similarity in [-1, 1]; a score of 0.80 corresponds to a cosine similarity of 0.60. No session or model is required. Use this SDK function for consistent scores across platforms.
