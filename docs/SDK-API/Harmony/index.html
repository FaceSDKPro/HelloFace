FaceFlowListener

Types
interface FaceFlowListener
Listener shared by one capture, liveness, or dynamic verification flow. onProgress may run multiple times. Normal business outcomes use onResult; an inability to finish uses onError. At most one terminal callback is delivered in total.

FaceFlowOutcome

Types
enum FaceFlowOutcome
Business outcomes after normal camera-flow completion. SDK processing errors are delivered separately through FaceFlowListener.onError. Include a fallback for unknown values to support future appended outcomes.

FaceFlowProgress

Types
class FaceFlowProgress
Current guidance stage for a camera flow. The action count is greater than 0 only when action challenges are configured.

FaceFlowResult

Types
class FaceFlowResult
Final camera-flow result. outcome is the business decision; optional scores are for display, audit, or threshold calibration. Undefined livenessScore or similarity means no corresponding score was produced, not a valid score of 0. Passive liveness uses the SDK's threshold of at least 0.90. Use outcome as the final decision.

FaceFlowStage

Types
enum FaceFlowStage
Current camera-flow guidance stage. Each flow uses only some stages. Display the current value without depending on a fixed order.

FaceSearchSession

FaceSearchSessionConfig

Types
class FaceSearchSessionConfig
Continuous face-search settings. Does not configure camera resolution, exposure, or capture frame rate. Both modes require face width and height of at least 100 px and use five-point alignment without 468-point or head-pose inference. After 10 seconds without a face, analysis drops to approximately 5 FPS and resumes immediately on detection.

FaceSearchStage

Types
enum FaceSearchStage
Current continuous-search stage. SUCCESS_INTERVAL is the wait after success before another round, not a terminal session state.

FaceVerificationApi

Types
interface FaceVerificationApi
Verification capability, obtained through HiFaceSdk.verification(). Similarity is not an identity probability.

FaceVerificationConfig

Types
class FaceVerificationConfig
1:1 verification settings. threshold is a face-feature similarity threshold, not a probability. For protection against replayed images, enable passive liveness and use a trusted random source to select distinct actions.

HeadPose

Types
class HeadPose
Smoothed head pose in degrees. Positive pitch means looking up, yaw is left/right rotation, and roll is rotation in the image plane.

HiFaceAccess

Fully offline and independent of inference sessions. The SDK verifies system identity and manages its protected status and integrity checks automatically.

HiFaceAccessInfo
