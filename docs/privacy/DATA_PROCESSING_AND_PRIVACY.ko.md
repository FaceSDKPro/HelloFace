적용 범위: HelloFace SDK. 이 문서는 SDK 통합 개발자 및 사업자를 대상으로 현재 데이터 흐름과 통합 주체의 데이터 관리 책임을 설명합니다. 통합 주체의 앱 또는 서비스의 개인정보 처리방침을 대신하지 않으며, 특정 배포가 규정 준수 인증을 받았음을 의미하지도 않습니다.

## 데이터가 처리되는 위치

SDK는 얼굴 검출과 캡처, 특징 추출, 라이브니스 검출, 비교 및 검색을 기기에서 수행합니다. SDK 자체는 데이터를 수집하거나 전송하지 않습니다.
SDK 계층은 네트워크 권한이나 네트워크 기능을 선언하지 않습니다. 호스트 앱은 카메라 권한, 사진 선택 및 네트워크 권한을 사용하는 목적을 설명해야 합니다.

## 처리되는 데이터

| 데이터 | 목적 및 처리 범위 |
|---|---|
| 카메라 프레임, 선택하거나 가져온 사진, 잘라낸 얼굴 이미지 | 검출, 캡처, 라이브니스 검출, 특징 추출 및 미리보기에 사용합니다. 원본 이미지를 추가로 저장할지는 앱 구현에 따라 결정됩니다 |
| 얼굴 특징값, 레코드 ID, 그룹 및 태그 | 기기 내 얼굴 데이터베이스의 등록, 조회 및 비교에 사용합니다. 등록하거나 가져온 레코드는 기기에 영구적으로 저장할 수 있습니다 |
| 로컬 SDK 실행 상태, 앱 설정 및 로그 | 운영 및 문제 진단에 사용하며 업무용 얼굴 데이터베이스와 별도로 관리합니다. 로그에도 데이터 최소화 원칙이 적용됩니다 |
| 운영체제 버전 및 하드웨어 모델 | SDK가 운영체제와 하드웨어 구성에 맞는 최적화된 실행 전략을 선택하는 데 사용합니다 |

## SDK 통합 주체의 책임

SDK 통합 주체는 사용 사례, 데이터 처리 활동, 배포 국가 또는 지역에 적용되는 요건에 따라 SDK를 통합한 앱이나 서비스에서 얼굴 데이터를 적법하게 처리하고 관리할 책임이 있습니다. 여기에는 수집, 이용, 저장, 접근, 공유, 이전 및 삭제가 포함됩니다. 또한 사용자에게 데이터 처리에 관한 명확한 설명과 관련 요청을 접수할 수 있는 창구를 제공하고, 해당 요청을 처리해야 합니다.

SDK의 현재 오프라인·온디바이스 아키텍처는 얼굴 데이터 연산을 기기 안에서 수행하여 설계 단계부터 사용자 데이터를 보호하고 외부 서비스에 얼굴 데이터가 노출될 위험을 최소화합니다. 앱이나 서비스가 자체적으로 구현하는 데이터 저장, 클라우드 동기화 또는 기타 처리에 대해서는 통합 주체가 접근 제어, 저장 데이터 보호, 보관 및 삭제 체계와 적용되는 고지·승인·보안 관리 조치를 마련해야 합니다.

현재 SDK는 12세 미만 아동의 얼굴 인식을 지원하지 않으며 금융 관련 용도로 사용할 수 없습니다.
