対象：HelloFace SDK。本書は SDK を組み込む開発者・事業者を対象とし、現在のデータフローと導入者のデータ管理責任を説明します。導入者のアプリやサービスのプライバシーポリシーに代わるものではなく、個別の導入環境についてコンプライアンス認証を受けたことを示すものでもありません。

## データ処理を行う場所

SDK は、顔検出・取得、特徴量抽出、ライブネス検出、比較、検索を端末内で実行します。SDK 自体がデータを収集・送信することはありません。
SDK レイヤーは、ネットワーク権限やネットワーク機能を宣言しません。ホストアプリは、カメラ権限、写真の選択、ネットワーク権限を使用する目的を説明する必要があります。

## 取り扱うデータ

| データ | 利用目的と処理範囲 |
|---|---|
| カメラフレーム、選択・インポートした写真、切り出した顔画像 | 検出、取得、ライブネス検出、特徴量抽出、プレビューに使用します。元画像を追加で保存するかどうかはアプリの実装によります |
| 顔特徴量、レコード ID、グループ、ラベル | 端末内の顔データベースへの登録、照会、比較に使用します。登録・インポートしたレコードは端末内に永続保存できます |
| SDK のローカル実行状態、アプリ設定、ログ | 動作と障害診断に使用します。業務用の顔データベースとは別に管理し、ログにもデータ最小化の原則を適用します |
| OS のバージョン、ハードウェアのモデル | SDK が OS やハードウェア構成に応じて最適な実行方式を選択するために使用します |

## SDK 導入者の責任

SDK 導入者は、利用シーン、データ処理の内容、導入先の国や地域で適用される要件に応じて、SDK を組み込むアプリやサービスにおける顔データを適法かつ適切に処理・管理する責任を負います。これには、収集、利用、保存、アクセス、共有、転送、削除が含まれます。また、利用者に分かりやすいデータ処理の説明と関連する請求の受付窓口を提供し、それらの請求への対応を行う必要があります。

SDK の現在のオフライン・オンデバイスアーキテクチャは、顔データの演算を端末内で完結させ、設計の段階から利用者のデータを保護し、外部サービスに顔データが露出するリスクをできる限り抑えます。アプリやサービスが独自に実装するデータ保存、クラウド同期、その他の処理については、導入者がアクセス制御、保存データの保護、保存期間と削除の仕組み、および適用される告知・許諾・安全管理上の措置を整える必要があります。

現在の SDK は 12 歳未満の子どもの顔認識に対応しておらず、金融関連の用途には使用できません。

SDK の組み込みに関するサポートや SDK のセキュリティ上の問題については、導入者から [FaceAISDK.Service@gmail.com](mailto:FaceAISDK.Service@gmail.com) までお問い合わせください。
