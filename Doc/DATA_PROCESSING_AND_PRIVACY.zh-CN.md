# 数据处理与隐私合规说明

[English](DATA_PROCESSING_AND_PRIVACY.md) | 简体中文 · [返回首页](../README.zh-CN.md)

适用范围：HelloFace 0.8.6 Beta 的 SDK 和公开 Demo。本文说明现有数据流程及接入方责任，不是宿主应用的隐私政策，也不表示任何具体部署已通过合规认证。SDK 使用限制和第三方许可仍分别适用。

## 数据在何处处理

SDK 在运行设备上进行人脸检测、采集、特征提取、活体与比对、搜索计算，不要求将摄像头帧或人脸特征发送到厂商服务。SDK 层不声明网络权限或网络能力。

Demo 是可修改的接入示例。Android、iOS 和 Harmony 的联网图片导入会请求所选图片地址；图片服务器可能接收 IP 地址及请求信息。相机权限、相册选择和网络权限的用途应由宿主应用说明。GitHub、APK 下载站、Web 在线体验及微信等外部服务各自处理其服务数据，不能把这些服务理解为 SDK 的离线计算。

## 涉及哪些数据

| 数据 | 用途和处理边界 |
|---|---|
| 相机帧、选择或导入的照片、人脸区域 | 检测、采集、活体、特征提取及页面预览；是否额外保存原图由应用实现决定 |
| 人脸特征、记录 ID、分组和标签 | 本机图库录入、查询和比对；录入或导入后可持久保存 |
| 相似度、活体结果及错误信息 | 展示计算结果和诊断；不能仅凭分数认定真实身份或安全性 |
| SDK 本机运行状态、应用设置、日志 | 支持运行和排障；与业务人脸库分别管理，日志也需遵循最小化原则 |

人脸特征并非天然匿名数据。特征编码、SDK 模型保护或应用签名不等于对业务图库、图片、导出文件或系统备份加密。应用应保护存储目录、访问权限、备份、导出和传输链路，并按实际风险采用静态加密和密钥管理。Demo 不是完整的生产数据安全系统。

## 保存、删除与资源使用

接入方决定必要的数据范围、保存期限及删除流程。关闭摄像头、退出页面或删除一条图库记录，不代表原始相册、其他图库、导出文件、缓存、日志、远程图源与系统备份一并删除。卸载行为受平台和备份配置影响，不应作为跨平台安全擦除承诺。

示例特征与图片索引仅用于演示，不是对任意外部图片、人脸或身份数据的商业使用许可。接入方应核实数据来源、处理依据和使用范围。不要把真实人脸库、个人照片、特征、密钥或设备状态提交到 Git、公开 issue 或公开日志。仅调用 Demo/SDK 不会自动把这些输入作为厂商训练数据上传。

## 部署前的责任

接入方应明确实际个人信息处理者、目的与必要性、告知和同意机制、权限范围、保存及删除规则，并提供个人行使权利的联系渠道。按处理活动落实访问控制、安全审计、风险评估、事件处理，以及依法需要的委托、共享和跨境安排。

在中国适用法律下，生物识别信息属于敏感个人信息；相关必要性、单独同意、未成年人保护及事前影响评估义务应由实际处理者核实并履行。参见《[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)》第二十八至三十一条、第五十五条。

《[人脸识别技术应用安全管理办法](https://www.cac.gov.cn/2025-03/21/c_1744174262156096.htm)》另涉及本机存储及对外传输限制、最短保存期限、替代验证方式和备案要求。请按具体适用条件执行；本机计算本身不等于全部合规义务已经完成。

当前模型不支持 12 周岁以下儿童人脸识别，不能用于金融相关场景。此产品限制与法律对不满 14 周岁未成年人个人信息的特别保护是不同要求，不能相互替代。境外部署还须评估当地规则。

个人数据相关请求请首先联系实际使用人脸数据的应用或服务运营方。SDK 集成及安全问题可联系 [FaceAISDK.Service@gmail.com](mailto:FaceAISDK.Service@gmail.com)；请先提供版本、脱敏错误码和最少必要的复现信息，不要直接发送个人照片或人脸特征。
